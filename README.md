## 🚀 How to Use

### 1. Clone the repository

```bash
git clone https://github.com/Sai-Srinivas-P/AI_TRAINING_NOTES.git
cd AI_TRAINING_NOTES
```

### 2. Create a Python environment

```bash
python -m venv .venv
```

Activate it:

**Windows**
```text
.venv\\Scripts\\activate
```

**Linux / macOS**
```bash
source .venv/bin/activate
```

### 3. Install the common data-science stack

```bash
pip install jupyter numpy pandas matplotlib seaborn scikit-learn tensorflow
```

Some notebooks may require additional packages or dataset-specific dependencies.

### 4. Start Jupyter

```bash
jupyter notebook
```

Open the notebook you want to study and run the cells sequentially.
